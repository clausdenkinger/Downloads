## Tile-Store-Testpakete

`Advanced-Sidebar-Tile-Store-Hello-World-Example.zip` enthält ein minimales Windows-Paket mit einem PowerShell-Workflow. Die ZIP-Datei wird in den konfigurierten Tile-Store entpackt; dort muss `hello-world-windows` als direktes Unterverzeichnis liegen.

Die SHA-256-Prüfsummen stehen in `SHA256SUMS.txt`.
